## Maintenance

GitHub Pages publishes from the `main` branch and `/ (root)`. Edit `index.html` and commit to `main` to update the site. No dependencies, build command or backend are required.

The repository contains `index.html`, this README, the optimized portrait `assets/mohamad-reza-mahvari-portrait.webp` and `assets/og-mahvari.png`, a 1200 × 630 social preview exported from SVG. The portrait uses a CSS crop so the source photograph remains intact. If the public URL changes, update the canonical and social URLs in `index.html` and the live link above.

Project summaries are kept at a high level to protect organizational confidentiality.

Designed as a single-page personal website with a focus on clarity, accessibility and a 30-second introduction experience.
